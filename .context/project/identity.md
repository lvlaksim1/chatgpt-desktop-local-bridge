# Project identity

## FACT — Identity

`lvlaksim1/chatgpt-desktop-local-bridge` is the product repository for a custom Windows ChatGPT desktop client that embeds ordinary `chatgpt.com` and provides a native Local Bridge for configurable access to the local computer.

The intended user authenticates with the normal ChatGPT web product and subscription. The product is not an OpenAI API client and does not depend on ChatGPT Work.

The project-local persistent Project Manager is `chatgpt-desktop-local-bridge-project-manager`. Durable manager state lives on `manager-state`; product truth lives on `main`.
