## Ближайшая разработка

1. Выделить в клиенте служебную сущность для нового канала, чтобы не заимствовать произвольную пользовательскую задачу в постоянной работе.
2. Реализовать в Local Bridge отправку команды:
   - сохранить новый текст служебной задачи;
   - выдержать минимум 5 секунд после завершения этого сетевого запроса;
   - вызвать штатную команду немедленного запуска.
3. Реализовать получение результата выполнения задачи.
4. Преобразовать ответ сервера в существующие локальные операции Local Bridge.
5. Начать с чтения текста и записи текста в файл.
6. Проверить тот же пользовательский сценарий D:\test\file.txt -> первая строка -> D:\test\file1.txt уже через установленный клиент.
7. Затем постепенно расширять набор нормальных локальных действий.
8. Только после формирования рабочей системы перейти к отказам, дублям, старым ответам и длительным испытаниям.
