# Намерения и обязательства

Поколение: 34.
Обновлено: 2026-10-06 15:27 MSK.

- Не продолжать подбор короткого времени расписания: для интерактивной работы использовать штатный немедленный запуск.
- Не использовать Library как обязательный промежуточный канал.
- Перенести из испытательного стенда в Local Bridge три части:
  1. запись команды в текст выделенной/служебной запланированной задачи;
  2. после обязательного пятисекундного интервала команда немедленного запуска;
  3. получение результата выполнения и передача структурированной локальной команды штатному исполнителю Local Bridge.
- Использовать существующую модель разрешений Local Bridge для локальных операций.
- В ближайшей разработке приоритет — полезная работа пользователя, а не расширение матрицы защитных испытаний.
- После нормального встраивания повторить простой файловый сценарий уже через установленный клиент, без PC Runner Gateway как промежуточного исполнителя.
