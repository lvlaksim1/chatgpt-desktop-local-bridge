# Намерения и обязательства

Поколение: 35.
Обновлено: 2026-10-07 17:50 MSK.

- Не развивать дальше эксперимент передачи задания через вложение, пока он не нужен конкретному продуктовому сценарию.
- Не использовать произвольную пользовательскую приостановленную задачу как постоянный серверный исполнитель `local.intent`.
- Исследовать штатное создание/получение отдельной служебной задачи Local Bridge и закрепить её идентификатор за клиентом.
- Для каждого запуска служебной задачи сохранять однозначные `request_id` и `message_id`, проверять соответствие ответа и не принимать старый результат.
- При неизвестном исходе изменяющего сетевого действия не выполнять слепой повтор: выдержать не менее 5 секунд и выполнить авторитетное чтение состояния.
- Серверная модель должна выдавать структурированные действия из зарегистрированного набора Local Bridge, а не неограниченный исполняемый текст.
- После подтверждения постоянной служебной задачи перейти к сущности многошагового локального задания и расширению постоянного журнала.
- Не переносить в основной пользовательский интерфейс исследовательские элементы; существующие исследовательские элементы позднее убрать в диагностический/разработческий режим.
