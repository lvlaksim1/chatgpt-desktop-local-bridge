# Текущие ограничения

Обновлено: 2026-10-07 17:50 MSK.

Основных препятствий для существующего пользовательского пути Local Bridge сейчас нет.

Главный архитектурный долг:
- `local.intent` зависит от наличия подходящей пользовательской приостановленной задачи;
- при каждом запросе её состояние временно изменяется и затем восстанавливается;
- постоянная продуктовая архитектура не должна вмешиваться в пользовательские задачи.

Не являются препятствиями:
- `Run Now` — доказан и встроен;
- получение `latest_backing_run` — доказано;
- локальное выполнение файловых действий — доказано;
- обычная модель умеет направлять локальную команду через мост;
- повторная передача bootstrap по кнопке «Мост» реализована;
- верхний 15-минутный предел `process.run` снят;
- Library не требуется.

Следующий блокирующий критерий перехода к многошаговым заданиям:
`local.intent` должен работать при нулевом количестве пользовательских приостановленных задач и использовать только собственную служебную сущность Local Bridge.
