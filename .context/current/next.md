# Следующие действия

Обновлено: 2026-10-06 15:27 MSK.

1. Перенести механизм "изменить текст задачи -> 5 секунд -> запустить сейчас" в код Local Bridge.
2. Перенести чтение результата выполнения в Local Bridge.
3. Подключить структурированные команды сервера к штатным локальным операциям чтения/записи файлов.
4. Создать постоянный служебный способ выполнения вместо временного использования чужой паузной задачи.
5. Собрать обновление клиента.
6. Повторить через установленный клиент пользовательскую команду:
   "Возьми D:\test\file.txt, извлеки первую строку и создай D:\test\file1.txt с этими данными".
7. После рабочего пользовательского пути расширять полезные локальные действия.
8. Проверки отказов и защиты проводить позже.
