# Следующие действия

Обновлено: 2026-10-07 17:50 MSK.

1. Создать новую рабочую ветвь от актуального `main` для постоянной служебной задачи `local.intent`.
2. Определить штатный запрос создания задачи и минимальный постоянный текст служебной задачи.
3. Создать отдельную задачу, принадлежащую Local Bridge, и сохранить её идентификатор в локальном состоянии клиента.
4. Перевести `LocalIntentPlanner` с поиска чужой приостановленной задачи на этот идентификатор.
5. Сохранить правило не менее 5 секунд между последовательными сетевыми запросами.
6. Реализовать восстановление: если служебная задача отсутствует, однозначно обнаружить это и безопасно создать/привязать новую.
7. Проверить `local.intent` при отсутствии пользовательских приостановленных задач.
8. Проверить простой файловый сценарий через установленный клиент.
9. После PASS перейти к проектированию многошагового локального задания и расширению `DurableRequestLedger`.
