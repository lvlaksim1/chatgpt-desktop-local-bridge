# Goose + Ollama — состояние проекта на 27.10.2026

## Цель
Локальный агент на Windows, использующий Qwen3.5 через Ollama, с русским интерфейсом, доступом к файлам и PowerShell. Управление установкой и испытаниями — через собственный Windows Runner Gateway.

## Рабочая среда
- Компьютер: Windows, RTX 2070 (8 ГБ), оперативная память 32 ГБ.
- Ollama 0.40.11: `D:\LocalAI\Ollama\bin\ollama.exe`, локальный API `http://127.0.0.1:11434`.
- Установленные модели: `qwen3.5:4b`, `qwen3.5:9b`; для Goose создан профиль `qwen3.5:4b-goose`.
- Goose CLI 1.56.0: `D:\LocalAI\Goose\bin\goose.exe`.
- Goose Desktop 1.56.0: `D:\LocalAI\Goose\desktop\v1.56.0\Goose.exe`.
- Рабочая папка, которую необходимо использовать: `D:\LocalAI\Goose\workspace`.
- Репозитории: [основной](https://github.com/lvlaksim1/chatgpt-desktop-local-bridge) и [Runner Gateway](https://github.com/lvlaksim1/pc-runner-gateway).

## Подтверждённые результаты
1. Ollama запущена как независимый от Runner Gateway процесс через Планировщик Windows. После завершения заданий Gateway сервер оставался доступен — [#430](https://github.com/lvlaksim1/pc-runner-gateway/issues/430), [#434](https://github.com/lvlaksim1/pc-runner-gateway/issues/434).
2. Qwen3.5 4B и 9B отвечают на запросы; короткие испытания проводились с ограниченным контекстом — [#433](https://github.com/lvlaksim1/pc-runner-gateway/issues/433).
3. **Причина ошибки Goose HTTP 503 при обращении к локальной Ollama:** прокси-переменные в окружении запущенного Goose. Подключение заработало после очистки HTTP_PROXY, HTTPS_PROXY, ALL_PROXY и настройки NO_PROXY для `127.0.0.1` и `localhost` — [#465](https://github.com/lvlaksim1/pc-runner-gateway/issues/465).
4. Goose через встроенный инструмент создал файл, содержимое совпало с контрольным — [#466](https://github.com/lvlaksim1/pc-runner-gateway/issues/466).
5. Выполнение команды из Goose подтверждено проверкой со случайным значением из переменной окружения — [#469](https://github.com/lvlaksim1/pc-runner-gateway/issues/469).
6. Рабочие запускатели CLI (подтверждение действий включено): `D:\LocalAI\Goose\Goose-Chat.cmd` и `D:\LocalAI\Goose\Goose-Agent.cmd` — [#470](https://github.com/lvlaksim1/pc-runner-gateway/issues/470).
7. Официальная графическая версия Goose установлена с русским интерфейсом большинства элементов — [#476](https://github.com/lvlaksim1/pc-runner-gateway/issues/476). Пользователь подтвердил её запуск скриншотом.

## Незавершённые задачи русского интерфейса
По пользовательскому скриншоту:
- Верхнее меню **File / Edit / View / Window** осталось английским.
- Подсказка **Attach file** осталась английской.
- В новом чате активная папка **C:\Users\Maksim**, а нужна **D:\LocalAI\Goose\workspace**.
- Часть других системных или технических строк также может оставаться английской.

При проверке исходников Goose Desktop 1.56.0 выявлено:
- В `ui/desktop/src/main.ts` перевод нативного меню Electron предусмотрен только для китайского языка. Для русского словаря нет.
- В `ui/desktop/src/components/ChatInput.tsx` текст `Attach file` задан непосредственно в компоненте и не локализован.
